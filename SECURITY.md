# Reporting security issues

For credentials exposure or vulnerabilities in this implementation, contact `2024302111167@whu.edu.cn` privately with affected versions and a minimal description. Please do not post live credentials or private traces in a public issue. No response-time guarantee is made.

Ordinary paper reproduction questions belong in Issues. The evaluated security behavior is defined by the paper's protocols; changes to the threat model should identify their input and attacker assumptions.
