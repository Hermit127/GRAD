# Checkpoints

Model binaries are excluded from the source checkout. The original supplementary package includes nine W1 models and three gate checkpoints; complete CAA expert checkpoints are not included there. Public distribution is pending a release decision.

When publishing a model artifact, record the model definition, input protocol, seed, threshold provenance, supported dependency versions, source commit, SHA-256, data provenance and applicable terms. Host model artifacts as versioned release assets or on a model hub and add real download links here after publication. Do not claim missing expert pools are available.
